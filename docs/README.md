# Project documentation

- [Equipment reservations: setup, behaviour and verification](equipment-reservations.md)

Store non-code project evidence here in clearly named folders as the project
progresses:

- `architecture/` — C4 diagrams, architecture decision records, data-model notes.
- `scrum/` — product backlog exports, sprint plans, estimates, task-board and
  burndown snapshots, reviews, and retrospectives.
- `testing/` — test cases and requirements-to-test traceability evidence.

Keep meeting recordings out of Git; store their unlisted-video links in the
relevant sprint evidence instead.
